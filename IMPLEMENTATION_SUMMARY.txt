HOW IT WORKS:
=============

BEFORE (Old - per trial):
  Trial 1: Create pool (50ms) → Run backtest → Destroy pool (30ms)
  Trial 2: Create pool (50ms) → Run backtest → Destroy pool (30ms)
  Trial 3: Create pool (50ms) → Run backtest → Destroy pool (30ms)
  Total overhead: 20 × 80ms = 1600ms

AFTER (New - process local):
  Trial 1: Create pool (50ms) → Run backtest → Reuse pool
  Trial 2: Get cached pool (0ms) → Run backtest → Reuse pool
  Trial 3: Get cached pool (0ms) → Run backtest → Reuse pool
  Total overhead: 2 × 50ms = 100ms

KEY FEATURES:
=============

✓ Automatic cleanup: atexit handler closes pools when worker exits
✓ Process-safe: Each worker process has its own isolated pool
✓ Backward compatible: No API changes, works transparently
✓ Works with both serial and parallel execution
✓ Simple implementation: ~100 lines of focused code
